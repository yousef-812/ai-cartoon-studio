# Golden Scene quality upgrade — implementation batch

Date: 2026-07-31

## Decision

The previous Golden Scene remains rejected for production use. This batch changes the production path rather than polishing the rejected output manually.

## M0 — Review evidence and promotion gate

Implemented:

- automatic media probing for the Golden Scene preview;
- deterministic SHA-256 recording;
- an eight-frame contact sheet generated by FFmpeg;
- a structured `output/golden-scene/review.json` artifact;
- `production_approved=false` and `promotion_blocked=true` by default;
- technical failure when video, audio, resolution, duration, sample rate, or channel checks fail;
- mandatory human-review questions before any production approval.

Artifacts:

- `scripts/build_golden_scene_review.py`
- `output/golden-scene/contact-sheet.png`
- `output/golden-scene/review.json`

Status: implementation complete; real Lightning artifact validation remains required.

## One-command production path

`scripts/run_demo_voiced_blender_preview.sh` now performs:

1. source compilation;
2. quality scene rebuild;
3. Piper voice generation/reuse;
4. deterministic ambience/effects generation;
5. manifest planning;
6. authored performance override application;
7. Blender rendering;
8. shot sound mixing;
9. preview assembly;
10. media probing, contact-sheet creation, and review-gate generation.

## Remaining blockers before M8 approval

- real Blender build and render validation in Lightning;
- visual review of the upgraded character silhouettes and facial readability;
- confirmation that authored reactions and eye lines read at normal speed;
- confirmation that rain, flicker, thunder, dialogue, and loudness are balanced;
- final artist-authored character meshes and facial deformation remain a later production-art milestone;
- Golden Scene human approval remains mandatory and cannot be inferred from successful media probes.
